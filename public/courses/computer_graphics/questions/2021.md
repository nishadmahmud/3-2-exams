**1. a) What is Computer Graphics? Describe different types of Computer Graphics.** [2+2]

> **Answer:**
> **Computer Graphics** is the creation, manipulation, and storage of geometric objects and images using computers.
> 
> There are two main types of Computer Graphics:
> 1. **Interactive Computer Graphics:** In this type, the user has control over the image by providing input (e.g., playing a video game or using drawing software). The image is updated dynamically based on user interaction.
> 2. **Non-Interactive (Passive) Computer Graphics:** The user has no control over the image. The graphics are simply displayed and act as a one-way communication (e.g., screensavers, movie rendering).

**b) What steps are required to plot a line whose slope is between 0° and 45° using slope-intercept equation?** [03]

> **Answer:**
> For a line where the slope $m$ is between 0° and 45° (i.e., $0 < m < 1$), the steps are:
> 1. Identify the starting point $(x_1, y_1)$ and ending point $(x_2, y_2)$.
> 2. Calculate the slope $m = \frac{y_2 - y_1}{x_2 - x_1}$ and the y-intercept $c = y_1 - m \cdot x_1$.
> 3. Start at $x = x_1$.
> 4. Calculate the corresponding $y$ value using $y = m \cdot x + c$.
> 5. Round the calculated $y$ value to the nearest integer.
> 6. Plot the pixel at $(x, \text{round}(y))$.
> 7. Increment $x$ by 1 and repeat from step 4 until $x$ reaches $x_2$.

**2. a) What do you mean by Scan-Conversion?** [2.5]

> **Answer:**
> **Scan-Conversion** (or Rasterization) is the process of converting geometric representations of objects (like lines, circles, polygons) into a discrete set of pixels that can be displayed on a raster scan screen. It determines which pixels on the screen matrix should be turned on to best approximate the continuous geometric object.

**b) Write the Bresenham's Line Generation Algorithm.** [05]

> **Answer:**
> **Algorithm Steps:**
> 1. Read the two endpoints of the line, $(x_1, y_1)$ and $(x_2, y_2)$.
> 2. Calculate $\Delta x = |x_2 - x_1|$ and $\Delta y = |y_2 - y_1|$.
> 3. Calculate the initial decision parameter $P = 2\Delta y - \Delta x$.
> 4. Initialize starting points: $X = x_1$ and $Y = y_1$.
> 5. Plot the first point: `putpixel(X, Y)`.
> 6. Loop from $k=0$ to $\Delta x$:
>    - If $P < 0$:
>      - $X = X + 1$
>      - $Y = Y$
>      - $P = P + 2\Delta y$
>    - If $P \ge 0$:
>      - $X = X + 1$
>      - $Y = Y + 1$
>      - $P = P + 2\Delta y - 2\Delta x$
>    - Plot the next point: `putpixel(X, Y)`.
> 7. End.

**d) What are the three major adverse side effects of scan conversion?** [04]

> **Answer:**
> The three major adverse side effects (often grouped under "aliasing") are:
> 1. **Staircase effect (Jaggies):** Slanted or curved lines appear jagged or stepped because they are approximated using discrete square pixels.
> 2. **Unequal brightness:** Diagonal lines appear dimmer than horizontal or vertical lines because the distance between pixel centers is greater diagonally ($\sqrt{2}$ vs $1$).
> 3. **Picket fence problem:** Thin objects that are perfectly aligned with the pixel grid may appear solid, but if shifted slightly between pixel centers, they may disappear or appear fragmented.

**3. a) What is Transformation? Write down the basic transformation matrices of geometric translation, scaling and mirroring.** [1+3]

> **Answer:**
> **Transformation** is the process of altering the coordinate positions of an object to change its size, shape, or orientation.
> 
> **Basic Transformation Matrices (in Homogeneous Coordinates):**
> 
> **Translation:**
> $$T(t_x, t_y) = \begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{bmatrix}$$
> 
> **Scaling:**
> $$S(s_x, s_y) = \begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix}$$
> 
> **Mirroring (Reflection across X-axis):**
> $$M_x = \begin{bmatrix} 1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

**b) Explain the eight-way symmetry of a circle. Find a transformation of triangle A(1,0), B(0,1), C(1,1) by:** [04]<br>
i. Rotating 45° about the origin and then translating one unit in x and y direction.<br>
ii. Translating one unit in x and y direction and then rotating 45° about the origin.

> **Answer:**
> **Eight-way symmetry:** If we calculate a single point $(x, y)$ on the perimeter of a circle centered at the origin, we can easily determine 7 other symmetrical points in the other octants: $(y, x)$, $(-y, x)$, $(-x, y)$, $(-x, -y)$, $(-y, -x)$, $(y, -x)$, and $(x, -y)$. This allows algorithms to compute just $1/8$th of the circle and map the rest.
> 
> **Transformations for Triangle A(1,0), B(0,1), C(1,1):**
> 
> **i. Rotate 45° then Translate (1, 1):**
> *Rotation ($\cos(45^\circ) = \sin(45^\circ) = 0.707$):* $x' = x \cdot 0.707 - y \cdot 0.707$, $y' = x \cdot 0.707 + y \cdot 0.707$
> - $A_{rot} = (0.707, 0.707)$
> - $B_{rot} = (-0.707, 0.707)$
> - $C_{rot} = (0, 1.414)$
> 
> *Translation (+1, +1):*
> - $A_{final} = (1.707, 1.707)$
> - $B_{final} = (0.293, 1.707)$
> - $C_{final} = (1.0, 2.414)$
> 
> **ii. Translate (1, 1) then Rotate 45°:**
> *Translation (+1, +1):*
> - $A_{trans} = (2, 1)$
> - $B_{trans} = (1, 2)$
> - $C_{trans} = (2, 2)$
> 
> *Rotation by 45°:*
> - $A_{final} = (2 \cdot 0.707 - 1 \cdot 0.707, 2 \cdot 0.707 + 1 \cdot 0.707) = (0.707, 2.121)$
> - $B_{final} = (1 \cdot 0.707 - 2 \cdot 0.707, 1 \cdot 0.707 + 2 \cdot 0.707) = (-0.707, 2.121)$
> - $C_{final} = (2 \cdot 0.707 - 2 \cdot 0.707, 2 \cdot 0.707 + 2 \cdot 0.707) = (0, 2.828)$

**(d) Write the versions of Shearing.** [2.5]

> **Answer:**
> The two main versions of Shearing are:
> 1. **X-Shear:** Shifts the X coordinates of points in a way that is proportional to their Y coordinates ($x' = x + sh_x \cdot y$). It skews the object horizontally.
> 2. **Y-Shear:** Shifts the Y coordinates of points in a way that is proportional to their X coordinates ($y' = y + sh_y \cdot x$). It skews the object vertically.

**b) Categorize the line which is found based on nine regions in Cohen Sutherland Line Clipping algorithm and assigned codes for each region.** [2.5]

> **Answer:**
> In the Cohen-Sutherland algorithm, lines are categorized based on their 4-bit Region Codes (TBRL):
> 1. **Trivially Accepted (Fully Visible):** If the logical `AND` of both endpoint region codes is `0000`, AND both original codes are `0000`. The entire line is inside the window.
> 2. **Trivially Rejected (Not Visible):** If the logical `AND` of both endpoint region codes is **NOT `0000`**. The line is completely outside the window.
> 3. **Needs Clipping (Partially Visible):** If the logical `AND` of both endpoint region codes is `0000`, but one or both of the original codes are **NOT `0000`**. The line crosses the window boundary and must be clipped.

> **Answer:**
> **Algorithm Steps:**
> 1. Assign a 4-bit region code (TBRL) to each endpoint of the line.
> 2. If both endpoints have the code `0000`, accept the line.
> 3. Else, perform a logical `AND` between the two codes.
>    - If the result is not `0000`, reject the line.
>    - Else (Needs Clipping), choose an outside point, find its intersection with the window boundary, and replace the outside point with the intersection point. Repeat until accepted or rejected.
> 
> **Applying Algorithm to Diagram Lines:**
> 
> ```text
> Case-1: P1 & P2
> -------------------------
> P1    0 0 0 1 (non zero)
> P2    0 0 0 1 (non zero)
> -------------------------
> AND   0 0 0 1 (non zero)
>       P1 - P2 (Rejected)
> 
> Case-2: P3 & P4
> -------------------------
> P3    0 0 0 0 (zero)
> P4    0 0 0 0 (zero)
> -------------------------
> AND   0 0 0 0 (zero)
>       P3 - P4 (Accepted)
> 
> Case-3: P5 & P6
> -------------------------
> P5    1 0 0 0 (non zero)
> P6    0 0 0 0 (zero)
> -------------------------
> AND   0 0 0 0 (zero)
>               (Clipping)
> Clip P5 - P5'
> 
> P5'   0 0 0 0
> P6    0 0 0 0
> -------------------------
> AND   0 0 0 0
>       P5' - P6 (Accepted)
> 
> Case-4: P7 & P8
> -------------------------
> P7    0 0 1 0 (non zero)
> P8    0 1 0 0 (non zero)
> -------------------------
> AND   0 0 0 0 (zero)
>               (Clipping)
> Clip P7 - P7'
> 
> P7'   0 0 0 0 (zero)
> P8    0 1 0 0 (non zero)
> -------------------------
> AND   0 0 0 0 (zero)
>               (Clipping)
> Clip P8 - P8'
> 
> P7'   0 0 0 0
> P8'   0 0 0 0
> -------------------------
> AND   0 0 0 0
>       P7' - P8' (Accepted)
> ```
> 
> **Final Accepted Lines:**
> - $P_3 - P_4$
> - $P_5' - P_6$
> - $P_7' - P_8'$

**5. a) Describe Text clipping with example.** [04]

> **Answer:**
> **Text clipping** is determining what part of text strings are visible inside the clipping window. The precision depends on the required accuracy:
> 1. **All or none string clipping:** The entire string is kept only if its bounding box is completely inside the window. Otherwise, the whole string is dropped.
> 2. **All or none character clipping:** Evaluates text character by character. If a character is completely inside, it's kept. If partially outside, that character is dropped.
> 3. **Text (Pixel-level) clipping:** Treats the text like an image. Only the specific pixels of the characters that fall inside the window are kept, cutting the letters precisely at the border.

**b) What conditions should be followed while we clip a polygon in Sutherland-Hodgeman polygon clipping algorithm.** [5.5]

> **Answer:**
> When testing polygon edges against a window boundary, the algorithm evaluates four conditions based on moving from vertex $V_1$ to vertex $V_2$:
> 1. **In $\rightarrow$ In:** If both vertices are inside the clipping boundary, the output is the second vertex ($V_2$).
> 2. **In $\rightarrow$ Out:** If the edge goes from inside to outside, the output is the intersection point ($V_2'$) at the boundary.
> 3. **Out $\rightarrow$ In:** If the edge goes from outside to inside, the output is both the intersection point ($V_1'$) and the second vertex ($V_2$).
> 4. **Out $\rightarrow$ Out:** If both vertices are outside the boundary, there is no output.
