**1. What do you mean by Token, Symbol Table and Lexeme? Write the functions of lexical analyzer.** [3+2]
> **Answer:**
> *   **Token:** A pair consisting of a token name and an optional attribute value (e.g., `<id, 1>`). It is the fundamental unit of meaning recognized by the lexical analyzer.
> *   **Lexeme:** The actual sequence of characters in the source code that matches the pattern for a token (e.g., `count`, `=`, `10`).
> *   **Symbol Table:** A data structure used by the compiler to keep track of semantics (like variable names, function names, types, and scope) as they are discovered during analysis.
> 
> **Functions of Lexical Analyzer:**
> 1. Reads the raw source code characters and groups them into meaningful sequences called lexemes.
> 2. Produces a stream of tokens corresponding to those lexemes for the syntax analyzer.
> 3. Strips out whitespace, tabs, newlines, and comments.
> 4. Correlates error messages with the source program (e.g., keeping track of line numbers).

**3. Describe the phase of compilers.** [4]
> **Answer:**
> The compilation process is divided into multiple distinct phases:
> 
> 1.  **Lexical Analysis (Scanner):** Reads the source code character stream and converts it into a stream of meaningful tokens.
> 2.  **Syntax Analysis (Parser):** Takes the token stream and generates a syntax tree to check if the code follows the grammatical rules of the language.
> 3.  **Semantic Analysis:** Checks the syntax tree for semantic consistency (e.g., type checking, variable declaration checks) with the language definition.
> 4.  **Intermediate Code Generation:** Converts the semantic tree into an explicit, machine-independent, low-level representation (like Three-Address Code).
> 5.  **Code Optimization:** Analyzes and improves the intermediate code to make the final program run faster or use less memory.
> 6.  **Target Code Generation:** Translates the optimized intermediate code into the specific machine language or assembly code of the target architecture.
> 
> *(Note: The Symbol Table Manager and Error Handler interact with all of these phases).*
